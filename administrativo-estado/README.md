# Administrativo del Estado

Nueva aplicación para validar una oportunidad de preparación digital de Administrativo de la Administración del Estado.

El proyecto parte de una landing mínima. El programa, el producto y los recursos se definirán antes de construir contenido completo.

## Desarrollo

```powershell
npm install
npm run dev
```

La aplicación no es oficial ni está vinculada a la Administración General del Estado.
