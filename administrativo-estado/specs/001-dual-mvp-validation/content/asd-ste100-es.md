# Guía de texto: ASD-STE100 adaptado al español

> **REFERENCIA HISTORICA.** Esta guía de estilo puede reutilizarse, pero no sustituye la especificación, la oferta ni el copy vigentes de 002-ss-casolab-academy.

ASD-STE100 controla el inglés técnico. Esta landing usa sus reglas de estructura y estilo en español. No declara cumplimiento formal del diccionario inglés.

## Reglas aplicadas

- Cada oración descriptiva tiene un máximo de 25 palabras.
- Cada oración contiene una idea principal.
- Cada párrafo contiene un solo tema.
- Cada párrafo tiene un máximo de seis oraciones.
- El texto usa voz activa cuando identifica al sujeto.
- Los verbos expresan acciones de forma directa.
- El texto usa una palabra constante para cada concepto.
- Las listas separan información compleja.
- Las llamadas a la acción usan el imperativo.
- El texto no usa punto y coma.
- Las condiciones aparecen antes de la acción cuando el lector debe conocerlas primero.
- Las siglas se explican en su primera aparición cuando el contexto no las hace evidentes.
