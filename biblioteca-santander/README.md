# Auxiliar de Biblioteca Santander · Academia LORMAN

Landing independiente para la convocatoria de Auxiliar de Biblioteca del Ayuntamiento de Santander, subgrupo C2.

## Alcance de la landing

La página se basa en las bases oficiales publicadas en el BOC de Cantabria y en el anuncio del BOE:

- 9 plazas: 8 de turno libre y 1 reservada a discapacidad.
- Oposición libre, subgrupo C2.
- 20 temas, divididos en parte general y parte específica.
- Primer ejercicio: cuatro supuestos prácticos en un máximo de dos horas.
- Segundo ejercicio: 50 preguntas tipo test en 50 minutos y cinco de reserva.

La propuesta se presenta como preparación en construcción. No se anuncia una fecha de examen, un precio definitivo ni un aula abierta que todavía no estén confirmados.

## Muestra gratuita

La landing incluye una prueba propia de 10 preguntas sobre el programa y 4 ejercicios de catálogo y obras de referencia, además de dos preguntas de reserva para practicar. Es una muestra educativa, no un cuestionario oficial.

## Desarrollo

```powershell
npm install
npm run dev
npm run test
npm run build
```
