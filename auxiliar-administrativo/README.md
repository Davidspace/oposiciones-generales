# Auxiliar Administrativo · hub de rutas

Landing transversal para presentar las rutas de Auxiliar Administrativo del Estado, del SAS y de futuras convocatorias locales.

## Desarrollo

```bash
npm install
npm run dev
```

Validación local:

```bash
npm run lint
npm run build
npm test
```

## Publicación

- Proyecto independiente de Vercel: `auxiliar-administrativo`.
- Dominio previsto: `https://auxiliar-administrativo.academialorman.es/`.
- No se añade automáticamente a la landing hub de Academia LORMAN.
- El proyecto de Santander queda archivado y separado; no forma parte de esta ruta.
