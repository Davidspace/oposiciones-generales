# Taxonomía de errores C2

| Código | Error | Señal de diagnóstico | Repaso automático |
|---|---|---|---|
| ORG-REC | Recuperación normativa | Confunde órgano, función o mayoría | Volver al mapa del tema y artículo |
| ORG-ALC | Alcance o excepción | Recuerda la regla general, no la excepción | Microbloque de excepciones |
| ACT-PLA | Plazos y cómputo | Falla en días hábiles, inicio o fin | Tabla de plazos + dos preguntas |
| ACT-PRO | Fases y recursos | Mezcla trámite, acto y recurso | Flujo del procedimiento |
| PS-V | Razonamiento verbal | Relación, orden o comprensión | Serie verbal graduada |
| PS-N | Razonamiento numérico | Operación, porcentaje o serie | Serie numérica con solución paso a paso |
| OF-WIN | Windows y archivos | Confunde ruta, carpeta o herramienta | Ejercicio de navegación |
| OF-WRD | Word | Confunde formato, estructura o impresión | Tarea breve de documento |
| OF-EXC | Excel | Confunde referencia, fórmula, función o dato | Hoja de cálculo guiada |
| OF-ACC | Access | Confunde tabla, consulta, formulario o relación | Diagrama de base de datos |
| OF-OUT | Outlook | Confunde regla, respuesta o reenvío | Flujo de correo |
| OF-WEB | Internet | Confunde navegador, protocolo o servicio | Glosario con ejemplos |
| GES-TIE | Gestión del tiempo | Deja demasiadas preguntas o arriesga sin criterio | Simulacro de 15/30/90 minutos |

El diagnóstico del producto solo describe patrones de respuesta. No equivale a una nota oficial ni predice un aprobado.
