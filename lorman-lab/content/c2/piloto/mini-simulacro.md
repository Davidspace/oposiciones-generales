# Mini-simulacro C2 — piloto local

Duración propuesta: **25 minutos** para las 32 preguntas del fichero `preguntas.json` o **5 minutos** para la muestra gratuita. El tiempo es una regla de experimentación, no una reproducción de la prueba oficial.

## Distribución

- 8 preguntas de organización pública.
- 8 preguntas de actividad administrativa.
- 8 preguntas psicotécnicas.
- 8 preguntas de ofimática.

## Reglas de diagnóstico

1. Una respuesta correcta por pregunta.
2. El producto puede mostrar la explicación tras responder.
3. El error se etiqueta con `taxonomia-errores.md`.
4. No se transforma la puntuación a una nota oficial.
5. El resultado recomienda un repaso; no predice el aprobado.

## Criterio de revisión

Antes de enlazar este simulacro desde una landing, una persona debe comprobar la clave, la explicación, la fuente, la dificultad y que no se copia un enunciado oficial.
