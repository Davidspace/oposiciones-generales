# Estructura de curso para Moodle · Celador/a-Subalterno/a SMS Murcia

Este documento es una guía de carga manual. No contiene credenciales ni modifica Moodle. Los documentos editoriales permanecen en el ZIP privado y deben cargarse solo después de cerrar las incidencias E-001 y E-002 del inventario.

## Etiquetas comunes

- `ORIENTACIÓN`: instrucciones, formato oficial y ruta de estudio.
- `MATERIAL PROPIO`: desarrollo, resumen o test creado para LORMAN.
- `REPASO ACUMULATIVO`: práctica combinada de varios bloques.
- `SIMULACRO PROPIO`: cuestionario LORMAN con formato de entrenamiento.
- `EXAMEN OFICIAL`: cuadernillo publicado por el SMS, con año, turno y modelo.
- `MATERIAL DE APOYO`: plantilla o corrección derivada; nunca sustituye al documento oficial.
- `EN REVISIÓN`: recurso que no debe mostrarse como definitivo.

## Secciones y actividades

### 00 · ORIENTACIÓN

1. Cómo utilizar el aula.
2. Formato del ejercicio: 75 preguntas, 85 minutos, cuatro opciones, −1/4 por error y en blanco sin puntuación.
3. Ruta recomendada: tema → resumen → test → repaso → simulacro.
4. Diferencia entre material propio, simulacro propio y examen oficial.
5. Registro personal de errores y revisión de normativa.

### 01 · TEMARIO COMÚN

Cada tema debe tener tres actividades, en este orden: `MATERIAL PROPIO · TEMA COMPLETO`, `MATERIAL PROPIO · RESUMEN` y `TEST TEMÁTICO · 50 PREGUNTAS · EN REVISIÓN`.

| Código | Tema |
| --- | --- |
| C01 | Constitución y Estatuto de Autonomía de Murcia |
| C02 | Sistema sanitario, mapa sanitario y Servicio Murciano de Salud |
| C03 | Estatuto Marco, derechos, deberes, promoción interna y disciplina |
| C04 | Situaciones administrativas, permisos y licencias |
| C05 | Relación electrónica, sede y responsabilidad administrativa |
| C06 | Prevención de riesgos, incendios y evacuación |
| C07 | Igualdad, discriminación, planes y acoso por razón de sexo |

### 02 · TEMARIO ESPECÍFICO

Cada tema sigue la misma plantilla de tres actividades. El programa específico debe mantenerse separado del común para evitar confusiones en la preparación de acceso libre y promoción interna.

| Código | Tema |
| --- | --- |
| E01 | Autonomía del paciente y protección de datos |
| E02 | Puestos hospitalarios, urgencias, anatomía, mortuorio y aislamiento |
| E03 | Rehabilitación, consultas externas y atención primaria |
| E04 | Almacén, farmacia y distribución de pedidos |
| E05 | Posiciones, movilización y traslados |
| E06 | Reprografía, envíos y servicios postales |
| E07 | Informática básica, almacenamiento y Windows |

### 03 · REPASOS

- Repaso acumulativo común.
- Repaso acumulativo específico.
- Repaso transversal común + específico.
- Banco personal de errores frecuentes.
- Diagnóstico por bloque y recomendación de siguiente actividad.

### 04 · SIMULACROS PROPIOS

Crear diez actividades con el mismo patrón:

`SIMULACRO PROPIO · SMS · 75 PREGUNTAS · 85 MINUTOS · EN REVISIÓN`

Cada actividad debe mostrar el tiempo, aplicar −1/4 por error, no puntuar respuestas en blanco, explicar cada respuesta y mostrar un resultado por bloque. No debe etiquetarse como examen oficial.

### 05 · EXÁMENES OFICIALES

Crear una carpeta por año, turno y modelo. En cada carpeta separar:

- `EXAMEN OFICIAL · CUADERNILLO`.
- `EXAMEN OFICIAL · PLANTILLA`.
- `MATERIAL DE APOYO · VERSIÓN CORREGIDA`, cuando exista.

Añadir una nota visible: el documento procede del SMS; una explicación derivada puede depender de normativa histórica y no sustituye la convocatoria ni la norma vigente.

### 06 · ACTUALIZACIÓN

- Fecha de última revisión editorial.
- Cambios normativos detectados.
- Cambios de convocatoria y avisos del BORM/MurciaSalud.
- Registro de recursos retirados o sustituidos.

## Secuencia de publicación segura

1. Hacer copia de seguridad del curso Moodle.
2. Crear secciones y etiquetas sin borrar cursos, usuarios ni bancos existentes.
3. Cargar un tema de prueba y un simulacro de prueba.
4. Comprobar PDF, DOCX, banco, puntuación, explicación y vista móvil.
5. Cargar el resto de recursos con la etiqueta editorial correspondiente.
6. Mantener ocultos los recursos `EN REVISIÓN`.
7. Publicar únicamente cuando la revisión jurídica y editorial esté registrada.
8. Matricular y dar acceso tras confirmar el pago por WhatsApp.
