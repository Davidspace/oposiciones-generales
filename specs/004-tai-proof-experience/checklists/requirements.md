# Requirements Quality Checklist

- [x] Los requisitos describen resultados observables.
- [x] Los escenarios cubren prueba y muestra; las reseñas quedan fuera de alcance hasta disponer de opiniones verificadas.
- [x] El alcance excluye backend, pagos y testimonios inventados.
- [x] Los criterios de éxito son medibles.
- [x] Las afirmaciones sobre el examen se limitan a la convocatoria vigente.
- [x] La experiencia móvil y accesible está incluida.
