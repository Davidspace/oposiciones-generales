# Checklist de revisión normativa

## Identidad y versión

- [ ] ID, versión, estado y propietario presentes.
- [ ] Convocatoria objetivo y fecha de corte presentes.
- [ ] Vigencia actual separada de la vigencia histórica.

## Fuentes

- [ ] Cada clave enlaza a fuente oficial directa.
- [ ] Artículo, disposición o sección identificados.
- [ ] Texto consolidado consultado en la fecha registrada.
- [ ] Correcciones, transitorias y notas del tribunal revisadas.
- [ ] No se usa un blog como fuente jurídica principal.

## Respuesta

- [ ] Los hechos permiten una única alternativa correcta.
- [ ] La explicación no excede lo que afirma la fuente.
- [ ] Las cuatro alternativas tienen explicación específica.
- [ ] Cuantías, plazos, porcentajes y edades se han recalculado.
- [ ] La puntuación se presenta como directa, no transformada.

## Cambios

- [ ] La matriz identifica todos los activos afectados.
- [ ] Se incrementó versión si cambió clave o explicación.
- [ ] Se registró el motivo y la fecha.
- [ ] Se retiró preventivamente contenido dudoso cuando procede.
- [ ] La revisión externa requerida está cerrada.
