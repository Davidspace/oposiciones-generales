# Borradores legales de SS CasoLab

**Estado:** no publicables. **Corte de fuentes:** 29 de julio de 2026.

Estos textos son una base operativa con campos `[[PENDIENTE: ...]]`. No sustituyen la revisión de un profesional ni autorizan la venta. `SS_CASOLAB_ORDERING_ENABLED` debe permanecer en `false` hasta que:

1. el titular complete identidad, NIF, domicilio, contacto, forma jurídica, fiscalidad y registro, si procede;
2. se aprueben producto, precio final con impuestos, inventario disponible, duración, calendario, soporte y política comercial;
3. se clasifique jurídicamente el curso —contenido digital, servicio digital, prestación de servicios o combinación— y se cierre el régimen de desistimiento;
4. se formalicen los encargos con hosting/D1, Moodle, email y cualquier otro proveedor;
5. se revise el uso de WhatsApp y el contrato de Bizum profesional;
6. una revisión jurídica externa apruebe la versión fechada que verá el comprador;
7. la interfaz guarde la versión y la evidencia separada de cada aceptación.
