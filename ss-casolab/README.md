# SS CasoLab

Aplicación y landing de preparación para Administrativo de la Seguridad Social, C1.

## Fuente editorial

La carpeta `SS/` contiene el temario de Alba y se conserva como fuente exacta:

- 23 temas generales.
- 13 temas específicos.
- Tests por temas.
- Simulacros.
- Normativa y fuentes oficiales.
- Informes y control de actualización.

La aplicación utiliza `content-source/` como derivado digital para diagnóstico, práctica y autocorrección. No sustituye a `SS/`.

## Desarrollo

```powershell
npm install
npm run dev
```

Ruta principal: `/ss-casolab`.

## Estado

La captación, el cobro y la publicación de contenido siguen sujetos a sus revisiones y configuraciones correspondientes.
